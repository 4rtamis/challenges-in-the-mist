# Lantern Template Editor

Lantern is a React + TypeScript editor for Mythos-style printable templates. The codebase is now organized around a shared template runtime so new templates can be added without copying challenge-specific glue.

## Developer Docs

- [Codebase Architecture](docs/codebase-architecture.md)
- [Adding a Template](docs/adding-a-template.md)

## Commands

```bash
npm install
npm run dev
npm run build
npm run lint
```
